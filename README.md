# 🏀 NBA 3PT Analysis — Κερδίζουν περισσότερους αγώνες οι ομάδες που σουτάρουν περισσότερα τρίποντα;

🇬🇷 Ελληνικά | [🇬🇧 English](README.en.md)

![Python](https://img.shields.io/badge/Python-3.14-blue) ![pandas](https://img.shields.io/badge/pandas-live--data-150458) ![License](https://img.shields.io/badge/License-MIT-green)

> **Σε μία γραμμή:** Το να σουτάρεις περισσότερα τρίποντα δεν εγγυάται νίκες από μόνο του — η επιθετική και αμυντική απόδοση (ORtg/DRtg) είναι οι πραγματικά καθοριστικοί παράγοντες.

Στατιστική ανάλυση της σχέσης μεταξύ στρατηγικής τριπόντων και αγωνιστικής επιτυχίας στο NBA, με **ζωντανό data pipeline** που τραβάει τρέχοντα στατιστικά απευθείας από το επίσημο API του NBA.

Ξεκίνησε ως εργασία στο μάθημα Στατιστικής (Πανεπιστήμιο Κρήτης) και εξελίχθηκε σε ανεξάρτητο project με πραγματικά, ανανεώσιμα δεδομένα.

## Ερευνητικά Ερωτήματα

1. **Ποιοι παράγοντες επηρεάζουν περισσότερο την απόδοση μιας ομάδας;** (πολλαπλή παλινδρόμηση, W/L% ~ ORtg, DRtg, Pace, TS%, 3PAr, 3P%)
2. **Διαφέρει το 3P% των ομάδων εντός και εκτός έδρας;** (t-test, σε επίπεδο αγώνα)
3. **Διαφέρει το 3P% ανάλογα με τη δύναμη του αντιπάλου;** (ANOVA, σε επίπεδο αγώνα)

## Ευρήματα

Τα παρακάτω αποτελέσματα αφορούν τη **σεζόν 2025-26** (πλήρης κανονική περίοδος). Αναπαράγονται με `--season 2025-26` (δες «Πώς τρέχει»).

| Ερώτημα | Αποτέλεσμα |
|---|---|
| 1. Βασικοί παράγοντες απόδοσης | Το backward elimination καταλήγει σε **ORtg**, **DRtg** και **TS%** (p < 0.05, R² = 0.95) |
| 2. Εντός vs Εκτός έδρας | Στατιστικά σημαντική διαφορά (t-test, p = 0.023) — ελαφρώς καλύτερο 3P% εντός έδρας (36.2% vs 35.5%) |
| 3. Δύναμη αντιπάλου | Στατιστικά σημαντική διαφορά (ANOVA, p = 0.038) — καλύτερο 3P% απέναντι σε αδύναμους αντιπάλους |

## Δομή Project

```
fetch_nba_data.py        # Τραβάει season-level στατιστικά ομάδων (ORtg, DRtg, Pace, 3PAr, 3P%, TS%)
analyze_regression.py    # Live regression + backward elimination για το Ερώτημα 1
analyze_game_level.py    # Τραβάει per-game δεδομένα και τρέχει τα Ερωτήματα 2 & 3
nba_season.py            # Κοινή λογική σεζόν (--season, προειδοποίηση για λίγους αγώνες)
make_plots.py            # Φτιάχνει τα τρία γραφήματα (q1_*.png, q2_*.png, q3_*.png)
NBAstats_live.csv        # Output του fetch_nba_data.py
NBA_gamelevel_live.csv   # Output του analyze_game_level.py
```

## Πώς τρέχει

```bash
pip install nba_api pandas scipy statsmodels matplotlib

python fetch_nba_data.py        # Πρώτα αυτό (τρέχουσα σεζόν, live)
python analyze_regression.py    # Ερώτημα 1
python analyze_game_level.py    # Ερωτήματα 2 & 3
python make_plots.py            # Γραφήματα
```

Από προεπιλογή το pipeline τραβάει **live** δεδομένα της τρέχουσας σεζόν, η οποία υπολογίζεται αυτόματα βάσει σημερινής ημερομηνίας. Για συγκεκριμένη σεζόν (π.χ. για να αναπαράγεις τα ευρήματα παραπάνω):

```bash
python fetch_nba_data.py --season 2025-26
```

Τα `analyze_*.py` διαβάζουν τη σεζόν από το CSV, οπότε τρέχουν αυτόματα στην ίδια σεζόν. Αν η σεζόν μόλις ξεκίνησε (λιγότεροι από 20 αγώνες ανά ομάδα), τα scripts εμφανίζουν προειδοποίηση ότι τα αποτελέσματα δεν είναι ακόμα αξιόπιστα.

## Μεθοδολογικές Σημειώσεις & Περιορισμοί

- Η αρχική εργασία του μαθήματος εξέταζε τα Ερωτήματα 2 και 3 σε επίπεδο **σεζόν** (30 ομάδες), χρησιμοποιώντας ως proxy το season-level 3P% και W/L%. Αυτή η έκδοση τα εξετάζει σωστά σε επίπεδο **αγώνα** (2400+ παρατηρήσεις), απαντώντας ακριβώς στο ερώτημα όπως τέθηκε αρχικά.
- Η κατηγοριοποίηση «δύναμης αντιπάλου» (Ερώτημα 3) βασίζεται στο **τελικό** W/L% της σεζόν — δηλαδή γνωρίζουμε εκ των υστέρων ποιος ήταν δυνατός, όχι το ρεκόρ τη στιγμή του συγκεκριμένου αγώνα. Αποδεκτή απλοποίηση, αλλά αξίζει να σημειωθεί ως περιορισμός.
- Οι μεταβλητές **Age** (μέση ηλικία ρόστερ) και **SOS** (Strength of Schedule) της αρχικής εργασίας παραλείφθηκαν σκόπιμα από το live pipeline: το Age δεν επιβίωσε στο backward elimination του αρχικού μοντέλου (άρα η αφαίρεσή του δεν επηρεάζει τα συμπεράσματα), και το SOS δεν είναι διαθέσιμο μέσω του επίσημου NBA API.
- Το τελικό μοντέλο του Ερωτήματος 1 εμφανίζει ήπια πολυσυγγραμμικότητα μεταξύ ORtg και TS% (αναμενόμενο, καθώς το TS% συμβάλλει στον υπολογισμό του ORtg) — τα αποτελέσματα είναι έγκυρα αλλά η ερμηνεία των επιμέρους συντελεστών πρέπει να γίνεται με προσοχή.
